## ✨ Возможности

| Возможность | Что делает | Модель | Цена |
|---|---|---|---|
| 🖼️ Нативные вложения изображений | В Desktop 0.2 / v0.1.6+ можно вставлять, перетаскивать или выбирать изображения, когда **активный маршрут поддерживает изображения**; маршрут по умолчанию `deepseek-flash` поддерживает. Текстовые маршруты отклоняют вложение с `MODEL_DOES_NOT_SUPPORT_IMAGES`; старая автотранскрипция больше не вызывается. | `deepseek-flash` по умолчанию или настроенный vision-маршрут | По условиям выбранного провайдера |
| 🔀 Цепочка резервирования vision | Для рабочих процессов с путями файлов `vision-review` может перебирать GLM-4V-Flash, DeepSeek Vision, Qwen3-VL, SenseNova, Gemini и пользовательские OpenAI-совместимые эндпоинты. | Ваши ключи и маршруты | Бесплатные лимиты или опциональные провайдеры |
| 👁️ `vision-review` | Анализирует локальные изображения и скриншоты, делает OCR, находит водяные знаки/логотипы и визуальные дефекты UI, может выдавать структурированные JSON-доказательства. Поддерживает длинные пути, пакетную проверку и `--structured`. | GLM-4V-Flash + опциональные vision-провайдеры | Бесплатные лимиты GLM/SiliconFlow, прочие опционально |
| 🎨 `media-tools` | Генерация картинок, иллюстраций, аватаров, фонов и баннеров | SenseNova U1 Fast → SiliconFlow Kolors | Бесплатно, без водяных знаков |

> ⚠️ Важно: в Desktop 0.2 нативные вложения принимаются только если активная модель объявляет `inputModalities: ["text", "image"]`. **Патч ядра не нужен**, нельзя изменять подписанный `app.asar`, и бандл не записывает настройки моделей. Для текстового маршрута вызывайте `vision-review` с локальным путём изображения.

## ⚡ Быстрый старт

1. Установите бандл:

   ```sh
   dsh plugin --profile <name> add github:MJorgin/dsh-media-skills
   ```

2. **Ключи**:
   - **Desktop 0.2 / v0.1.6+**: для установки ключи не нужны — оба навыка регистрируются в рантайме, а маршрут по умолчанию `deepseek-flash` поддерживает нативный диалог с изображениями. Ключи для цепочки навыка (`GLM_API_KEY`, `SILICONFLOW_API_KEY`, опционально `GEMINI_API_KEY`) хранятся в `~/.dsh/secrets/media-tools.env`; дополнительные маршруты настраиваются в **Настройки → Модели**.
   - **Старые превью ≤ v0.1.1**: тогда чтение вставленного изображения и vision-маршрут могли использовать существующий ключ агента `DEEPSEEK_API_KEY`. Это поведение автотранскрипции не относится к Desktop 0.2.

   ```sh
   # ~/.dsh/.credentials.yaml (chmod 600)
   GLM_API_KEY: <ваш ключ>
   ```

3. **Полностью перезапустите** `dsh web` и жёстко обновите страницу (`Cmd+Shift+R`).

4. Проверьте: **`vision-review`** и **`media-tools`** появляются в списке навыков. В Desktop 0.2 перед отправкой нативного вложения выберите маршрут с поддержкой изображений, например **`deepseek-flash`**; текстовый маршрут вернёт `MODEL_DOES_NOT_SUPPORT_IMAGES` и не опишет картинку автоматически.

Полное руководство, принцип работы и решение проблем: **[../SETUP_VISION.md](../SETUP_VISION.md)**

## 🔑 Ключи

Ключи **никогда не хранятся в этом репозитории**. Отдельная цепочка `vision-review` читает по порядку: переменные окружения → `~/.dsh/secrets/media-tools.env` → `~/.codex/secrets/media-tools.env` (устаревший запасной вариант). Старая автоматическая настройка GLM-маршрута относится только к ≤ v0.1.1; в Desktop 0.2 / v0.1.6+ маршруты управляются в **Настройки → Модели**.

Где получить ключи для движков навыка (бесплатные лимиты — по условиям провайдеров): Zhipu — [open.bigmodel.cn](https://open.bigmodel.cn) → API Keys (glm-4v-flash). SiliconFlow — [siliconflow.cn](https://siliconflow.cn) → API Keys (Kolors). Google Gemini можно опционально добавить в цепочку резервирования.

```sh
# ~/.dsh/secrets/media-tools.env (chmod 600, одна пара KEY=value в строке)
GLM_API_KEY=...
SILICONFLOW_API_KEY=...
```

## 🚀 Использование

Три способа читать изображения:

| Способ | Как | Когда |
|---|---|---|
| **A. Нативное вложение (рекомендуется)** | Выберите маршрут с поддержкой изображений (по умолчанию `deepseek-flash`), затем нажмите 🖼️ / перетащите / вставьте изображение и отправьте | Обычные мультимодальные вопросы по картинкам |
| **B. Сессия с vision-моделью** | В новом диалоге выберите `deepseek-flash` или настроенный GLM/Qwen/SenseNova-маршрут и вставляйте изображения | Многоходовые нативные диалоги про изображения |
| **C. Файлы + навык** | Положите изображение в workspace и скажите «прочитай через vision-review» либо запустите `scripts/vision.py` с путём | Пакетная проверка, структурный OCR/QA, текстовые маршруты |

Нативные вложения отправляются напрямую выбранной vision-модели. В `vision-review` язык и формат ответа можно задать в запросе или использовать `--structured`.

Просто скажите:

- «Посмотри на эту картинку / проверь этот скриншот на визуальные баги» → `vision-review`
- «Сгенерируй изображение …» → `media-tools`

## 🔌 Совместимость

| Сборка DSH | Статус |
|---|---|
| Desktop **0.2.0-rc.2** | **Проверено в рантайме.** Стандартный рантайм-плагин; оба навыка регистрируются через `ctx.skills.registerProvider()`. Нативные вложения допускаются только при `inputModalities: ["text", "image"]`; маршрут по умолчанию `deepseek-flash` это поддерживает. Без патчей ядра и записи настроек. |
| Тег **dsh-v0.2.1-rc.2** | **Проверено по исходникам.** `@deepseek-ai/dsh-skill@0.2.1-rc.2` сохраняет factory provider, `list()`/`get()`, поля candidate и допуск изображений. Локально не было упакованной сборки rc.2 Desktop для полного теста запуска. |
| **v0.1.6** | Тот же поддерживаемый жизненный цикл provider; опциональные GLM/SiliconFlow/SenseNova/Gemini маршруты настраиваются в **Настройки → Модели**. |
| v0.1.1 и более старые превью | Только историческое поведение. Не применяйте старые патчи ядра к подписанным сборкам Desktop 0.2. |

Полный чек-лист проверок — в [заметках о совместимости Desktop 0.2](../DESKTOP_0.2.md).

### Совместное использование с ModLens

Бандл можно установить вместе с [ModLens](https://github.com/liustack/modlens), но в Desktop 0.2 больше нет старого запасного пути api-proxy с автотранскрипцией. Осознанно выберите workflow ModLens «вставка → путь» либо `pasteToPath: false`, чтобы нативные вложения отправлялись в модель с поддержкой изображений. Историческое сравнение на китайском — [../COMPARE_MODLENS.md](../COMPARE_MODLENS.md).
